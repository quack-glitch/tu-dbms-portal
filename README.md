# Tribhuvan University — BSc CSIT: Database Management System (CSC265)

A comprehensive, modern, mobile-responsive study portal and solution bank for **Tribhuvan University (TU), Institute of Science and Technology (IOST)**, 4th Semester **BSc Computer Science and Information Technology (BSc CSIT)**.

---

## 🌟 Features

- **8 Years of Past Exam Papers (2076–2082)**:
  - 2082, 2081, 2080 (new), Model Question, 2080, 2079, 2078, 2076.
  - Exactly 96 questions mapped to Section A (10 Marks) and Section B (5 Marks).
- **Verified Solutions with 44 Diagrams**:
  - Full step-by-step explanations, ER diagrams, 3NF/BCNF decomposition tables, transaction state diagrams, 2PL lifecycle flows, and immediate/deferred recovery architectures.
  - Interactive solution toggle (`View Solution` / `Hide Solution`) with global `Expand All` / `Collapse All`.
- **45-Hour Official Syllabus Breakdown**:
  - Detailed topics and hour distributions for all 10 units.
  - Unit-by-unit priority tags derived from historical recurrence.
- **Top 15 Ranked PYQ Matrix**:
  - Evidence-backed recurrence frequency table from 8 exam papers.
  - Identifies recurring question patterns and blindspots.
- **⚡ Rapid Recall Revision Cards**:
  - High-yield flashcards for key definitions, differences (e.g. 1NF vs 2NF vs 3NF vs BCNF, Wait-Die vs Wound-Wait, Immediate vs Deferred update).
- **Interactive Tools**:
  - Real-time global keyword search across all questions and solutions.
  - Dark Mode / Light Mode with persistent local storage.
  - One-click print and PDF generation via `@media print` styling.
  - Quick-copy button for code snippets and solutions.

## 💻 Local Setup

Clone the repository and open `index.html` in any browser:

```bash
git clone https://github.com/quack-glitch/tu-dbms-portal.git
cd tu-dbms-portal
# Open in browser directly:
start index.html
```

Or run with any local HTTP server:
```bash
python -m http.server 8080
```
Then visit `http://localhost:8080`.
